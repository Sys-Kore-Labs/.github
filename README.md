# Curso desde cero: HTML, CSS y JavaScript

Bienvenido. Este curso está pensado para alguien que **empieza desde 0**.

## Plan del curso

1. **Fundamentos de la web**
   - Qué son HTML, CSS y JavaScript

3. **CSS (diseño)**
   - Colores, fuentes, tamaños y espacios

4. **JavaScript (interacción)**
   - Variables, condicionales, bucles y funciones
   - Manipulación del DOM
   - Eventos de clic, teclado y formularios
5. **Proyectos prácticos**
   - Página personal
   - Landing page
   - App interactiva simple
6. **Buenas prácticas**
   - Orden de archivos y estructura
   - Cómo practicar sin frustrarte
   - Cómo seguir aprendiendo

## Clase 1: ¿Qué son HTML, CSS y JavaScript?

Piensa en una casa:

- **HTML** = la estructura (paredes, puertas, habitaciones).
- **CSS** = el diseño (colores, estilo, tamaño, decoración).
- **JavaScript** = la interacción (luces que se encienden, puertas automáticas).

### ¿Cómo funciona una web?

1. El navegador (Chrome, Edge, Firefox) abre un archivo HTML.
2. Lee el CSS para aplicar estilos.
3. Ejecuta JavaScript para agregar comportamiento.
